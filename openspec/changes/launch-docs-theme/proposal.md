## Why

The current branch proves the shadcn-based UI but modifies the upstream OpenAPI theme and demo directly, carries unused OpenAPI runtime dependencies for docs-only consumers, and creates a large rebase conflict surface. We need a clean, public docs theme and starter now while preserving the fork relationship, attribution, and a low-conflict path for future upstream updates.

## What Changes

- **BREAKING**: Rename the public theme package from `docusaurus-theme-shadcn-docs` to `@aeei/docusaurus-theme`.
- **BREAKING**: Make the first public package docs-only; remove OpenAPI rendering and OpenAPI runtime dependencies from the core theme.
- Add a new additive `packages/docusaurus-theme` package that layers selected docs UI seams over Docusaurus classic and publish version `0.1.0` publicly as `@aeei/docusaurus-theme`.
- Standardize all interactive primitives on official shadcn Base Nova source backed by Base UI; remove Radix runtime usage.
- Add `examples/docs-starter` for Markdown, GFM, MDX, and Mermaid authoring with autogenerated navigation and semantic theme tokens.
- Restore upstream-owned OpenAPI packages and `demo/` to `origin/main` after the new package reaches parity.
- Replace upstream project branding, navigation, footer, Algolia credentials, and screenshots in the public starter and root README.
- Publish the starter at `https://aeei.github.io/docusaurus-theme/` through GitHub Pages and set that URL as the repository homepage.
- Keep search disabled until this site receives its own Algolia DocSearch application/index; never reuse upstream credentials.
- Add complete license and third-party provenance files to the repository and published package.
- Keep `origin/main` as the fork mirror and rebase `shadcn-theme` onto it; avoid direct edits to upstream-owned paths.

## Capabilities

### New Capabilities

- `docs-theme-package`: Installable `@aeei/docusaurus-theme` package with Base UI-only docs navigation, content, code, responsive, and color-mode UI.
- `docs-authoring`: Starter authoring experience for Markdown, GFM, MDX, Mermaid, static assets, autogenerated sidebars, and semantic token customization.
- `public-docs-site`: GitHub Pages build/deployment, project README with real light/dark screenshots, repository metadata, and optional own-index DocSearch rollout.
- `source-attribution`: Accurate footer links, acknowledgements, license texts, provenance records, and package-tarball notice guarantees.

### Modified Capabilities

None. This repository has no existing OpenSpec capability specs.

## Impact

- New paths: `packages/docusaurus-theme`, `examples/docs-starter`, OpenSpec capability specs, Pages workflow, license/notice assets, README screenshots.
- Restored paths: `packages/docusaurus-theme-openapi-docs`, `packages/docusaurus-plugin-openapi-docs`, `packages/create-docusaurus-openapi-docs`, and `demo` must match `origin/main` at completion.
- Dependencies: add official Docusaurus Mermaid support; retain Base UI and Lucide; remove Radix and OpenAPI runtime dependencies from the public core package.
- Public interfaces: package name, Docusaurus theme registration, semantic CSS token contract, starter content paths, Pages URL, and optional Algolia environment variables.
- Repository operations: rename-aware `origin`, rebase-only history, GitHub Pages configuration, About metadata, npm scope ownership, and future DocSearch application.
