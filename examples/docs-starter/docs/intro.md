# Starter overview

This starter shows a docs-first setup for **@aeei/docusaurus-theme** with Markdown, GFM, MDX, and Mermaid enabled.

![Starter preview](/img/docs-hero.svg)

## Included routes

- [Markdown + GFM guide](./guides/markdown-gfm)
- [MDX playground](./showcase/mdx-playground)
- [Mermaid examples](./showcase/mermaid)

## What it demonstrates

- semantic neutral tokens in `src/css/tokens.css`
- autogenerated docs sidebar from local folders
- project-owned navbar/footer without search credentials
- Pages-ready config for `https://aeei.github.io/docusaurus-theme/`
